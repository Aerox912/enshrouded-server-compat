# Historical adapter research tools

These scripts preserve the remaining local research from the original
enshrouded-vein-mining-server working folder (5 October 2026). The adapter,
extras, tests and vendored sources already exist in the maintained repository.
Its proxy and CMake changes are superseded by the maintained implementation.

These are historical scripts, not deployment entry points. Some contain fixed
local staging paths or write patched resources in those staging directories.
Do not run them against a live server or use their old assumptions as current
server configuration. Use tools/Prepare-Server.ps1 and the current deployment
records instead. No game binaries, worlds or private allowlists are archived.
